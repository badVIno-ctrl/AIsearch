# 🔍 Vision Search

> Нейропоиск картинок в папке - по **описанию** (даже на русском!) или по **загруженному фото**.
> Внутри - нейросеть CLIP, удобный чат-интерфейс и запуск «в один клик».

## ✨ Что умеет

- 🗣️ **Поиск по описанию** — напиши «рыжий кот» или «red sports car», и найдёт.
- 🖼️ **Поиск по фото** — загрузи/перетащи/вставь картинку, найдёт похожие.
- 🔀 **Гибрид** — фото + текст одновременно («как это, но красное»).
- 🌐 **Многоязычность** — русские запросы работают благодаря multilingual-модели.
- 🔤 **OCR** — находит картинки по тексту внутри них (если установлен tesseract).
- 🏷️ **Авто-теги** — каждой картинке автоматически подбираются метки.
- 🧩 **Похожие / дубликаты** — кнопка «похожие» и поиск почти-дублей.
- ⚙️ **Удобство** — порог схожести, смена папки, переиндексация с прогресс-баром.
- 🎨 **Красивый UI** — тёмная/светлая тема, история, избранное, экспорт, превью.
- ⚡ **Кэш** — векторы считаются один раз, повторный запуск — мгновенный.

## 🚀 Быстрый старт

### Вариант 1 - самый простой (без гемора)

**Windows:** дважды кликни `run.bat`

**macOS / Linux:**
```bash
chmod +x run.sh   # только первый раз
./run.sh
```

Скрипт сам создаст окружение, скачает библиотеки и откроет браузер на
**http://127.0.0.1:5000**. Нужен только установленный [Python 3.9+](https://python.org)
(на Windows поставь галочку «Add Python to PATH»).

> ⚠️ Первый запуск долгий: качается нейросеть (~1–2 ГБ). Дальше — секунды.

### Вариант 2 - вручную
```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

### Вариант 3 - Docker
```bash
docker compose up --build
# потом открой http://127.0.0.1:5000
```

## 📂 Как подключить свои фото

В комплекте уже есть демо-база картинок в папке `images/`.
Чтобы искать по своим фото:

1. Либо положи свои картинки в папку `images/`.
2. Либо вверху сайта в поле **«Папка»** впиши путь к любой своей папке и нажми **«Открыть»**.

Приложение само проиндексирует новую папку (с прогресс-баром) и запомнит её.

## 🧠 Как это работает

В основе — модель **CLIP**. Она переводит и картинки, и текст в одно и то же
векторное пространство. Значит, можно напрямую сравнивать «текст ↔ картинка»
и «картинка ↔ картинка» по косинусной близости.

```
запрос (текст или фото)
        │
        ▼
   [ CLIP ] ──▶ вектор запроса
        │
        ▼
  сравнение с векторами всех картинок (кэш)
        │
        ▼
   топ-N самых похожих → красивая выдача
```

## 🗂️ Структура проекта

```
vision-search/
├─ app.py                 # веб-сервер Flask + все роуты API
├─ core.py                # чистая логика: индекс, поиск, хэши, дубликаты
├─ model.py               # обёртка над нейросетью CLIP + OCR + автотеги

├─ download_model.py      # скачать модель заранее (для оффлайна)
├─ templates/index.html   # страница (чат-интерфейс)
├─ static/style.css       # стили (тёмная/светлая тема)
├─ static/app.js          # логика интерфейса
├─ images/                # демо-база картинок (можно заменить на свои)
├─ tests/                 # тесты на логику поиска
├─ requirements.txt       # зависимости
├─ run.sh / run.bat       # запуск в один клик
├─ Dockerfile / docker-compose.yml
└─ build_exe.py           # сборка .exe через PyInstaller
```

## ⚙️ Настройки (переменные окружения)

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `HOST` | `127.0.0.1` | адрес сервера |
| `PORT` | `5000` | порт |
| `NO_BROWSER` | — | `1` — не открывать браузер автоматически |
| `CLIP_IMAGE_MODEL` | `clip-ViT-B-32` | модель для картинок |
| `CLIP_TEXT_MODEL` | `…multilingual-v1` | модель для текста (многоязычная) |
